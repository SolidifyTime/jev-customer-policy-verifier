# 客服业务规则任务：基础模型补充评测

2026-10-04 已独立加载原始 Qwen3-0.6B，完成客服业务规则合规判别的验证集与测试集评测。基础模型两项准确率均为 50.00%，全部预测为合规。在相同小写输入与 Direct 协议下，原始数据一轮微调的测试准确率为 96.84%，比基础模型高 46.84 个百分点。

基础模型的测试混淆矩阵为 `[[395, 0], [395, 0]]`，行是真实合规/违规，列是预测合规/违规。验证矩阵为 `[[365, 0], [365, 0]]`。两个分区均为标签均衡数据，所以始终预测合规得到 50%，没有有效区分合规和违规；0% 误报率不能单独作为有效性证据。

相比基础模型，原始组在测试集改正 381 道违规题，同时新增 11 道合规误报，净多答对 370 题，即提升 46.84 个百分点。混合组改正 386 道违规题，新增 22 道合规误报，净多答对 364 题，提升 46.08 个百分点。
