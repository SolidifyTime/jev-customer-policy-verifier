# AutoDL CUDA 12.4 环境适配与验证

记录范围：这是三轮训练与 TensorBoard 启用前的环境适配记录，当时正式预算为 600 次更新。本页环境组合仍沿用；最新实现、日志验证与交付包见 [三轮训练与 TensorBoard 记录](tensorboard-epochs-20261004.md)。当时的包已归档到 `runs/archive/packages/llamafactory-direct-torch260-cu124-steps600-v1/`。

2026-10-04 根据 AutoDL 的镜像与主机兼容限制，将实际训练环境调整为 **Ubuntu 22.04 / Python 3.12 / PyTorch 2.6.0 + cu124 / RTX 4090**。使用平台的 PyTorch 2.5.1 / Python 3.12 / CUDA 12.4 基础镜像开机，再创建独立 Conda 环境安装训练依赖。当前步骤见 [环境指南](../guides/autodl-environment.md)。

## 依赖核定与改动

- 官方 PyTorch CUDA 12.4 三件套为 torch 2.6.0、torchvision 0.21.0、torchaudio 2.6.0。
- LLaMA-Factory 0.9.5 的依赖范围允许 torch 2.6.0；Transformers 4.57.6 的 optimizer、scheduler 恢复检查要求 torch ≥2.6。
- 共同依赖的三件套、CUDA 专用依赖、自检和 CPU CI 已同步；其余 13 个直接依赖沿用此前版本。
- 训练继续使用自定义 Direct Trainer、原生 Qwen3 预训练骨干与词表头、A/B 受限交叉熵和全参数更新；ModelScope 下载当前官方版本，后续本地加载。

依据为 [PyTorch 官方版本页](https://pytorch.org/get-started/previous-versions/#v260)、[LLaMA-Factory 0.9.5 依赖声明](https://github.com/hiyouga/LlamaFactory/blob/v0.9.5/pyproject.toml)和 [Transformers 恢复加载检查](https://github.com/huggingface/transformers/blob/v4.57.6/src/transformers/utils/import_utils.py#L1532)。镜像内安装包不会升级宿主机驱动；CUDA 是否可用需要在 AutoDL 上执行实际内核检查。
